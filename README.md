# Oliva

Oliva adalah website resep makanan sederhana untuk kebutuhan portfolio junior frontend.
Project ini dibuat untuk menampilkan layout website yang responsive, navigasi antar halaman.

## Stack

- React
- Tailwind CSS
- Vite

## Fitur

- Responsive layout untuk desktop dan mobile
- Mobile menu yang bisa dibuka dan ditutup
- Search/filter sederhana untuk kategori dan resep
- Multi-page hash navigation tanpa routing library tambahan
- Komponen reusable untuk header, footer, recipe card, team member, dan section layout

## Halaman

- Home: hero video, kategori resep, latest posts, author intro, newsletter, CTA, dan footer
- About: intro author, story section, CTA, team section, dan footer
- Recipes: hero recipes, search input, most loved recipes, dan daftar kategori resep

## Cara Menjalankan Project

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

Lint project:

```bash
npm run lint
```
